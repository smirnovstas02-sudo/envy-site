# Сайт для Енви

Полноценный сайт: страница и маленький сервер, который хранит общую ленту посланий
(их видят все посетители в реальном времени). Зависимостей нет, нужен только Node.js 18+.

## Запуск у себя

    node server.js

Откройте http://localhost:3000

## Выложить в интернет

Нужен хостинг, где можно запустить Node.js: Render, Railway, Fly.io или обычный VPS.

**Render / Railway (проще всего):**
1. Загрузите эту папку в репозиторий на GitHub.
2. Создайте Web Service из репозитория. Build command пустой, Start command `node server.js`.
3. Чтобы послания не пропадали при перезапуске, подключите постоянный диск (Disk / Volume)
   и задайте переменную окружения `DATA_DIR` на путь к нему, например `/data`.
   На бесплатных тарифах без диска файл сообщений может сбрасываться.

**VPS:** `npm i -g pm2 && pm2 start server.js && pm2 save`, перед ним nginx или Caddy с HTTPS.
Для SSE в nginx добавьте `proxy_buffering off;`.

## Настройка

- Дата для счётчика дней: в `public/index.html` строка `const TOGETHER_SINCE = "";`
- Лимиты отправки (1 письмо в 8 секунд, 30 в час с адреса): функция `allowed` в `server.js`
- Свой домен подключается в настройках хостинга.

## Удалить нежелательное послание

Откройте `data/messages.json` (или `DATA_DIR/messages.json`), удалите нужную запись и перезапустите сервер.
